This folder holds a backup of an older, single-file frontend implementation.

## Files
- `request.jsx.bak` — A backup React file that contains older app code, including forms, API helpers, validation, tracking, toasts, and modal logic.
- `README.md` — This file.

The `.bak` extension marks `request.jsx.bak` as a backup. The active shared UI folder is `components/`, with an “s”.
