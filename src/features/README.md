# client/src/features/

## Purpose
This folder groups app screens by what they do.

## Files
- `README.md` — This file. There are no source files directly inside this folder.

## Dependencies
- `history/` — The recent-request button and drawer, imported by `App.jsx`.
- `request/` — The request form, verification, review, and success screens, imported by `App.jsx`.
- `signature/` — Signature and requester fields, used by the request screen.
- `track/` — The request tracking form, imported by `App.jsx`.

## Notes
Each feature folder has its own README with more details.
