# client/src/styles/

## Purpose
This folder contains the CSS for the app, its forms, and its legal pages.

## Files
- `app.css` — Styles the home page, cards, forms, dialogs, controls, and responsive layouts.
- `legal.css` — Styles the legal pages, consent and review sections, footer, and focus states.
- `README.md` — This file.

## Dependencies
`main.jsx` imports both CSS files. The styles use class names from the React components and theme values passed to forms.

## Notes
These are CSS files; they do not contain JavaScript functions.
