# client/public/

## Purpose
This folder holds images that the frontend can load by their public URL.

## Files
- `lcr.jpg` — The City Civil Registrar office logo. `App.jsx` shows it on the home page; the backend email template also uses its public URL.
- `scc.png` — The San Carlos City seal. `App.jsx` shows it on the home page; the backend email template also uses its public URL.
- `README.md` — This file.

## Dependencies
The frontend refers to the images as `/lcr.jpg` and `/scc.png`. The backend email template uses URLs for the same images.

## Notes
These are static image files. This folder has no JavaScript code.
